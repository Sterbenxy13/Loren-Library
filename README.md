## Installing
For install and test this project, you need to:
* Move all the files to your localhost server folder, like as "wamp64/www/Loren-Library-main/";

* In your mySql server, create a database named as "loren-library", and import the "/sources/loren-library.sql" file;

* In the file "wp-config.php" located in the main directory, set up the "DB_USER", "DB_PASSWORD" and "DB_HOST", if it's needed, according with your hosting settings for the correct connection;

* In your browser, connect with the link "localhost/Loren-Library-main", to access the website.
